# random_passord_generator_basic
A random password generator written in BASIC.

Random Password Generator in BASIC is licensed under GPLv3.

This program is written in Bywater BASIC 3.20.

You can download Bywater BASIC 3.20 for your system at https://sourceforge.net/projects/bwbasic/

INSTALL

Just save rpg.bas to a folder. Cloning will do this automatically.

EXECUTE

To execute in terminal or shell, navigate to the folder or directory where you stored the rpg.bas file. Then type:

bwbasic rpg.bas

or 

bwbasic.exe rpg.bas

BTW, if you are using Windows, it is helpful to either have bwbasic.exe file reference in PATH or the file in the same directory as rpg.bas.

USAGE

The program will ask how many characters. This is how many characters you want the password to be.
After entering a number, it will process and come up with a new password. You should be able to highlight and copy the password right from the terminal or shell window.
Then you can apply the new password to whatever system you desire via paste.

Note that the script takes some time to execute as it's running through an interpreter app rather than being a compiled app.
